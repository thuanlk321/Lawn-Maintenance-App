### ✨ Overview

Lawn Maintenance App is a desktop application that helps customers easily book lawn care services and allows admins to manage services and assign workers efficiently.

The app provides two main roles:

- **Customer**: Browse services, select date, place orders and view booking history
- **Admin**: Manage services (add/edit/delete) and assign workers to jobs

### 🛠️ Key Features

**For Customers**
- Easy signup / login
- Select lawn care services
- Choose preferred date
- Submit order & view booking history

**For Admins**
- Add / Edit / Delete services
- Set service prices
- Assign workers to jobs
- Manage the entire service list
